System Architecture and Methodology

CineMatch is built as a modular hybrid recommendation system combining two distinct paradigms:

Content-Based Filtering

Constructs a unified textual feature soup per movie from genres, release year, and crowd-sourced user tags. Vectorized via TF-IDF with sublinear term-frequency scaling and evaluated using pairwise cosine similarity.

Collaborative Filtering

Constructs a sparse user-item interaction matrix from 100,836 ratings. Decomposed via Truncated Singular Value Decomposition (SVD) with 20 latent components to discover hidden community taste patterns and predict unobserved ratings.

Hybrid Fusion

Scores are normalized and blended dynamically: S_hybrid = alpha * S_content + (1 - alpha) * S_collab. This eliminates single-paradigm vulnerabilities like the cold-start problem and over-specialization.
